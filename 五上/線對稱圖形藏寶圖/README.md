# 線對稱藏寶圖 v2

## 已完成

- 五關題目由8、10、12、13、16格逐步增加，採三關垂直、兩關水平對稱。
- 可選方向變化、依序闖關或自由選關。
- 每關獎勵只發放一次；相同答案重複檢查不重計，空白答案不算錯。
- Pointer Capture 與插補處理拖曳塗格；取消事件會停止畫筆，支援鍵盤及復原。
- 提示依序為觀念、對應位置及一格示範，原則上重試三次後開放。
- 導覽留在版面內，棋盤依寬度縮放。
- 續玩、逐關用時／重試／提示紀錄、本機篩選及 CSV 匯出。
- `cloud.js` 已準備 HighGrade Firebase、匿名學生登入及指定教師 Google 登入。

## 雲端啟用前置條件

目前雲端保持停用。使用者已要求「權限設定最後交我確認」，不得只因程式上線就啟用。

1. 取得使用者對教師帳號、登入供應商、網站網域及資料規則的最後確認。
2. 重新備份當下 HighGrade 規則，合併核准的新規則，保留其他遊戲的索引與路徑權限。
3. 確認 Google／匿名登入及 `hctsao.github.io` 授權網域。
4. 以教師、匿名學生與未登入狀態驗證規則後，設定 `symmetryTreasure/config/cloudEnabled: true`。
5. 檢查跨裝置上傳與教師查詢，確認學生無法取得別人的紀錄。

`cloud.js` 會檢查未登入者能否讀取 records；若仍公開，拒絕上傳資料。
過往 Supabase 錯題未刪除、未自動移轉。新版完整紀錄先留在本機，啟用後同步最近保留的待傳紀錄。
本機最多保留2000筆；雲端後台查最近1000筆，頁面會標示查詢範圍。
